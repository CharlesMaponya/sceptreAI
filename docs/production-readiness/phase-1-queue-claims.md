The immediate gaps are abandoned-upload cleanup before committed ownership and native outbox handlers, including managed analysis cancellation, that retain SQL across Kubernetes/storage mutations. Existing outbox claims, tracking lookup leases, upload verification, local profiling and refit reconciliation provide useful split-transaction patterns, but are not blanket qualification for all workers.

Next changes must preserve legal holds, retention/provider identity, exact native versions, current fences, immutable receipts, retry ownership and unknown native-operation custody. Moving I/O outside a transaction without first defining ownership and post-I/O publication checks would leave the task unfinished. Required follow-up checks include replica races, process death, connection loss and replay, using the approved local fixtures before native/release qualification.

Native credential removal, source-current release/runtime checks, actual prior-binary compatibility and the 45 GB migration remain required. The original abandoned `phase1-deletion:G7` is still a required handoff for seven missing historical QA objects.
